# ROASaurus for Claude Code

A Claude Code plugin marketplace with one plugin, `roasaurus`: the ROASaurus MCP server plus skills and commands for
ad audits, wasted spend and tracking health on your webshop's ad accounts.

## Install

```
/plugin marketplace add roasaurus/claude-code
/plugin install roasaurus@roasaurus
```

Then run `/mcp`, pick `roasaurus` and sign in. See [plugins/roasaurus/README.md](plugins/roasaurus/README.md) for what
the plugin contains and what it needs.
